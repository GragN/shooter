# Sniper 3D

Экспериментальный 3D-симулятор стрельбы с внешней баллистикой,
разрушаемыми бетонными объектами и стальной мишенью. Проект написан на C# для .NET 8 и использует
[OpenTK](https://opentk.net/) для окна, ввода и OpenGL-рендеринга.

## Возможности

- баллистика с фиксированным шагом и интегрированием RK4;
- сопротивление воздуха по моделям G1/G7, ветер, гравитация и spin drift;
- СВД, ПМ, РПК и Barrett M82A1 с отдельными профилями боеприпасов;
- пристрелка на дистанции до 2000 м и прогноз точки попадания;
- разрушаемые бетонный куб и дом с физическими обломками;
- третья сцена: круглая пластина S355 диаметром 1 м, толщиной 10 мм;
- вмятины, сквозные отверстия, пробитие и рикошет от стали с потерей энергии и массы пули;
- камеры стрелка, пули и наблюдателя у цели.

## Требования

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0);
- видеокарта и драйвер с поддержкой OpenGL 3.3;
- графическая среда Windows, Linux или macOS.

## Запуск

```bash
dotnet restore
dotnet run --project Sniper3D.csproj
```

Сборка Release:

```bash
dotnet build Sniper3D.csproj -c Release
```

## Управление

| Действие | Управление |
| --- | --- |
| Наведение | Мышь |
| Выстрел | Левая кнопка мыши |
| Включить или выключить оптику | Правая кнопка мыши |
| Изменить дистанцию пристрелки | Колесо мыши |
| Баллистический прогноз | `T` |
| Камеры стрелка, пули и цели | `1`, `2`, `3` |
| Отключить отдачу и покачивание | `O` |
| Настройки сцены | `M` |
| Восстановить разрушаемую цель | `R` |
| Повернуть стальную пластину на 5° | `[` и `]` (английская раскладка) |
| Выход | `Esc` |

В меню `M` можно выбрать сцену, оружие, дистанцию, кратность оптики и
максимальную скорость ветра.

## Стальная сцена

Откройте `M`, выберите третью кнопку `STEEL 10MM`, затем `APPLY`.
Пластина — обычная конструкционная сталь S355 с номинальной массой 61,65 кг,
жёстко закреплённая в стойке. `[` и `]` меняют угол от 0 до 75°.
Камера `3` показывает пластину крупным планом и оставляет вид стрелка в PIP.
`R` очищает вмятины, отверстия и частицы; угол при этом сохраняется.

Для первого знакомства: дистанция 100 м, ветер 0, `ZERO 100 m`, `O`, Barrett.
ПМ в этой модели останавливается; мощная пуля может пробить лист и продолжить
полёт с меньшей массой и энергией. Попадание под большим углом может вызвать
рикошет. Отверстия сохраняются, и последующие пули могут пройти через них.

Модель учитывает толщину, угол, свойства стали и конструкцию пули, но её
коэффициенты пока не откалиброваны по испытаниям конкретного листа и патронов.
Это инженерная игровая аппроксимация, а не обещание совпадения с реальным
испытанием. Формулы и ограничения: [docs/steel-model.md](docs/steel-model.md).

## Проверки

Физические тесты не требуют видеокарты или дисплея:

```bash
dotnet run --project Tests/Sniper3D.PhysicsTests.csproj -c Release
```

Графический smoke-тест требует работающий дисплей и OpenGL 3.3:

```bash
dotnet run --project Tests/Sniper3D.GraphicsTests.csproj -c Release
```

Он автоматически запускает все три сцены, меню, наблюдателя/PIP и реальные
игровые выстрелы в сталь. При ошибке проверки процесс завершается с ошибкой.

## Структура проекта

- `Ballistics/` — профили оружия, интегратор полёта, сопротивление и ветер;
- `Destruction/` — бетон, сталь, столкновения, повреждения и обломки;
- `Rendering/` — OpenGL-ресурсы, mesh и shader;
- `Game/` — игровой цикл, ввод, камеры, меню, HUD и рендеринг сцены.
- `Tests/` — физические проверки и графический smoke-тест;
- `docs/` — описание материальных моделей и их ограничений.

`SniperGame` разделён на partial-файлы по ответственности. Физически скрытые
воксели не отправляются на рендеринг, а OpenGL uniform locations кэшируются
на время жизни shader-программы.
